# Templo Singular — Página Pós-Compra

Projeto estático pronto para GitHub + Vercel.

## Estrutura
- `index.html` — página completa
- `assets/` — foto, logos e captura da Circle

## Publicar no Vercel
1. Crie um repositório no GitHub.
2. Envie o conteúdo desta pasta para a raiz do repositório.
3. No Vercel, clique em **Add New > Project**.
4. Importe o repositório.
5. Framework Preset: **Other**.
6. Não precisa configurar Build Command.
7. Clique em **Deploy**.

## Observação
As fontes usadas são Playfair Display + DM Sans via Google Fonts.
